Voice — narration voice, speed, pitch

Pick a voice style, then speed/pitch. Voices here are browser Gemini voices (your key): Thiha-style uses a Gemini male voice, Nilar-style uses a Gemini female voice, Gemini AI uses Kore. This page does not run Edge Thiha/Nilar voices — those labels are style choices for the Gemini voice, not the Edge engine.

Voice: Thiha-style (Gemini male voice). Needs a Gemini key for auto voice; without a key, use original video audio.

Default +25% (faster narration). Speed changes narration timing and the video is re-timed to match, so subtitles stay in sync.

Pitch is applied in-browser as a playback-rate change for narration audio only (Gemini TTS itself has no pitch control), and narration timing is re-synced, so it does not break subtitle timing. Original-audio mode ignores pitch.

ℹ️ Details — audio & speed

Audio modes use MediaRecorder (canvas video + Web Audio track); they may be slower and less frame-accurate than WebCodecs. Sound may play aloud during an audio-mode render — lower the speaker volume (capture is internal, so it does not mute the recording). If the output is still silent, report the log line "Audio track:". Speed uses the browser playback rate, so it is approximate; the final summary reports the actual output duration.
